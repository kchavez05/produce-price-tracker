# v1.5.1 — Data Explorer & Score Transparency

Retrospective record (November 11, 2026): [closed milestone v1.5.1](https://github.com/kchavez05/produce-price-tracker/milestone/13); original [GitHub publication](https://github.com/kchavez05/produce-price-tracker/releases/tag/v1.5.1) dated 2026-10-29 (America/Denver). See the [release audit](retrospective-audit-2026-11-11.md#v151) for verified gates, gaps and follow-ups. Earlier preparation steps below remain historical context.

PantryBot now connects its grocery recommendations to inspectable market evidence. The public **Explore the data** footer link opens `/data`, where any visitor can compare stored USDA benchmarks with observed store advertisements, follow score calculations, understand ingredient groupings, and inspect source rows.

## Delivered

- Price charts across all archived stores, weekly price patterns, observed-window statistics, visible missing weeks, and a keyboard-accessible table alternative.
- Exact value-score traces using the same calculation as the dashboard: affordability, discount depth, market signal, weights, intermediate rounding, and final score. Action tags, cycle badges, and freezer suggestions have separate explanations.
- Ingredient catalog with recipe-role grouping rationale, matching keywords/exclusions, USDA mappings, package conversions, and labeled static baselines.
- A first-class Raw data view covering original USDA market rows, normalized observations, archived store offers/retrieval receipts, and calculated results. Chart points link to their contributing evidence.
- Filtered CSV exports with provenance metadata and spreadsheet-formula protection; lazy JSON inspection and downloads of audited public projections of preserved USDA reports, including unmapped market rows.
- Read-only server archive queries, bounded windows and payloads, revision inspection, snapshot validation, and explicit recovery from changed/expired snapshots.

## Policy and correctness changes

Yellow and white cooking onions remain grouped for supported cooked recipe roles. Sweet, red, and green onions are excluded, and the name no longer implies a mandatory 3 lb bag. Source varieties remain separate in the raw data; a PantryBot recipe group is not a USDA commodity classification.

A large regular-price discount alone no longer earns a “six-week low” badge. The badge also requires a price within $0.05 of the observed low, at least 32% off regular price, and six verified local weeks. Discount-only cases receive a deep-discount label. Scoring weights remain 55/35/10; the verified-history path explicitly shows its neutral six-point market-signal contribution.

Previously usable USDA versions remain admitted even if they predate the acceptance ledger. Synthetic demonstration observations now have stable prices and IDs across filtering and chart drill-through. Snapshot changes produce an explicit reload path rather than silently replacing paginated results.

## Data and production configuration

The existing archive contains twelve USDA source weeks ending August 7 through October 23, 2026: sixty report versions and 1,030 normalized observations across five reports. Store history currently contains eighteen offer revisions from one observed week. Sparse local history remains sparse; the explorer never manufactures verified observations.

Production uses the existing server-only `SUPABASE_SECRET_KEY` and Supabase URL. A preview without server database credentials enters labeled demonstration mode even when production history exists. No production credentials are copied into previews for this release. Explicit `mode=demo` links continue to select demonstration data.

The reviewed `read_data_explorer` function has already been applied to the production database. It is `SECURITY INVOKER`, callable only by `service_role`; browser-role table/function restrictions remain intact. Full-report downloads are sanitized market-field projections with USDA attribution, not byte-original API envelopes. The archive's 4 MB report cap remains enforced.

This release does not change provider polling, ingestion schedules, retention, or personal inventory/account ownership. USDA data is currently national advertised retail pricing, not wholesale momentum or a local shelf-price survey.
