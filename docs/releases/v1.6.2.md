## Candidate contents

- **#646 — Typed barcode entry.** Validate UPC-A/EAN-13 while preserving original digits and leading zeros. Show USDA product/source/package information separately from a proposed generic cooking ingredient. Review, correction/custom entry and explicit confirmation reuse private pantry persistence; lookup never adds inventory automatically or sets its amount from package size.
- **#647 — Camera capture.** Deliberate local start/resume, supported formats, pause after a valid capture, late-result fencing and track cleanup on close/hide/unmount. Camera denial/unavailability retains typed entry and ingredient search. Frames stay local; capture fills digits and still requires lookup/review/confirmation.
- **#648 — Pinned lookup delivery and abuse controls.** Verified read-only snapshot delivery, complete artifact hashing, lossless compaction, lookup-only function tracing and a conservative size guard. Approved controls are 30 POST attempts/IP/60-second fixed window **per edge region**, including failures; the browser deadline is 2.5 seconds, body-read timeout 2 seconds and function ceiling 5 seconds. Protected Preview qualification is recorded; production-scoped enforcement and enabled runtime acceptance remain required.
- **#650 — Shared static/unpriced staple estimates.** Current recipes, saved reevaluation and shopping use one evaluator, preserving reviewed static values, exact-unit boundaries, Yes/No ownership, optional details and pinned/dietary choices. Unknown prices stay unpriced; allocated recipe-use cost is distinct from package checkout cost. Repricing does not write inventory or saved documents.

New live staple/store API pricing is outside MVP under the [approved scope amendment](../research/v1.6.2-static-pricing-scope-amendment.md). [Multi-store parent #689](https://github.com/kchavez05/produce-price-tracker/issues/689) owns unscheduled #651/#652 across multiple independent retail APIs. Existing market-discovery integrations are preserved; no new provider is admitted or enabled by this release preparation.
