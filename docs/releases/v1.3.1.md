## Executive Summary

PantryBot `v1.3.1` establishes a **comprehensive 3-tier automated test suite and branch-aligned CI quality gate** enforcing code quality, arithmetic safety, database isolation, zero-key offline resilience, and security across all pull requests and releases.

The suite runs on **Vitest** with Node 22 native SQLite and is split into:
1. **Tier 1 (Unit Testing Policy):** Runs on working branches (`feature/*`, `fix/*`, `chore/*`, `docs/*`) in `< 1s` covering pure domain math, flyer price normalization, scoring curves, wholesale club benchmarks, store trip splits, rate limiters, and cart export formatters.
2. **Tier 2 (Smoke Testing Suite):** Runs on Pull Requests targeting `develop` in `< 2s` verifying SQLite schema/seed health, core route handlers (`/api/dashboard`, `/api/locations`, `/api/freezer`, `/api/saved-recipes`), and the zero-key offline fallback for `/api/ai-meal-plan`.
3. **Tier 3 (Regression Testing Suite):** Runs on Release Pull Requests targeting `main` in `< 3s` exercising multi-constraint meal prep permutations, account sync/GDPR purge lifecycles, freezer weighted-average cost depletion, weekly sync cron digests, and CSRF/rate limit abuse boundaries.

## Key Capabilities & Highlights

### 1. Test Architecture & Framework Setup
- **Vitest ESM Config (`vitest.config.mts`):** Native TypeScript resolution, fast watch mode, and isolated Node 22 execution.
- **SQLite In-Memory Test Isolation (`src/lib/db/sqlite.ts`):** Added `PANTRYBOT_SQLITE_PATH=':memory:'` and `resetSqliteTestInstance()` to eliminate filesystem mutations during test execution.
- **Strongly Typed Test Factories (`tests/test-utils.ts`):** Modular factory helpers (`createMockDish`, `createMockOffer`, `createMockCommodity`, `createMockIngredient`) ensuring full type safety and maintainability.

### 2. Tier 1: Unit Test Policy (`npm run test:unit`)
- **Flyer Price Normalizer (`tests/unit/backend/flipp-normalizer.test.ts`):** Tests BOGO detection, multi-buy bundles ("4 for $5", "3/$6"), bag weights (5 lb -> $/lb), ounce packages, and egg dozen conversions.
- **Commodity Value Scoring & Wholesale Arbitrage (`tests/unit/backend/scoring-and-wholesale.test.ts`):** Tests affordability curves, discount depth, dynamic USDA overrides, and Costco/Sam's Club benchmark comparisons.
- **Shopping List & Store Trip Optimizer (`tests/unit/backend/shopping-list-optimizer.test.ts`):** Tests ingredient quantity aggregation across dishes, `$0.00` Virtual Freezer out-of-pocket substitution, and 2-store split recommendation thresholds.
- **Store Registry & Banner Resolvers (`tests/unit/backend/store-registry.test.ts`):** Validates ZIP-based regional banner mappings for Kroger and Safeway families across multiple states.
- **Security & Rate Limiting (`tests/unit/backend/rate-limit-security.test.ts`):** Fixed-window rate limit buckets, same-origin verification, open-redirect path sanitization, and secure cookie configuration.
- **Cart Exporter & Curbside Links (`tests/unit/frontend/cart-exporter.test.ts`):** Clean query token generation, curbside deep-links across 7 providers, and markdown clipboard formatting.

### 3. Tier 2: Smoke Test Suite (`npm run test:smoke`)
- **SQLite Schema & Persistence Health (`tests/smoke/backend/sqlite-health.test.ts`):** In-memory schema creation, historical seed checks, CRUD operations, and sync run logging.
- **API Route Handlers Happy-Path (`tests/smoke/backend/api-routes-smoke.test.ts`):** In-process route execution for `/api/dashboard`, `/api/locations`, `/api/freezer`, `/api/saved-recipes`, and offline fallback validation for `/api/ai-meal-plan`.

### 4. Tier 3: Regression Test Suite (`npm run test:regression`)
- **Dashboard Permutations (`tests/regression/backend/dashboard-permutations.test.ts`):** Dietary constraints (`GLUTEN_FREE`, `DAIRY_FREE`), cooking vessel archetypes (`DUTCH_OVEN_BRAISE`), pinned/on-hand prioritization, and 4/6/8 serving scaling.
- **Account Sync & GDPR Lifecycle (`tests/regression/backend/account-sync-gdpr.test.ts`):** Local SSO profile creation, guest-to-cloud data merge, GDPR JSON export archive, and right-to-be-forgotten cascading purge.
- **Freezer Cost Basis & Depletion Lifecycle (`tests/regression/backend/freezer-lifecycle.test.ts`):** Weighted-average cost calculations across successive purchases, partial depletion via PATCH, and automatic deletion upon zero quantity.
- **Weekly Sync Cron & Digests (`tests/regression/backend/connectors-and-cron.test.ts`):** Execution of weekly circular sync, push notification generation (`WEDNESDAY_AD_DROP`, `SPLURGE_ALERT`, `FRIDAY_PREP_DIGEST`), markdown digest, and SQLite audit logging.
- **Security Boundaries & CSRF Rejection (`tests/regression/backend/security-boundaries.test.ts`):** Verifies 403 Forbidden on cross-origin mutations across `/api/freezer`, `/api/sync`, and `/api/account`, plus 429 Too Many Requests on burst requests.

### 5. Flyer Per-Pound Normalizer Bugfix
- Enhanced `src/lib/connectors/flipp.ts` to flexibly match `/ lb` (with whitespace) in addition to `/lb`, preventing explicit per-pound flyer items from misidentifying as each/count items.

### 6. GitHub Actions CI Pipeline & Documentation
- **`.github/workflows/ci.yml`:** Updated CI Quality Gate to enforce Tier 1 on working branches, Tier 1 + Tier 2 on PRs to `develop`, and Tier 1 + Tier 2 + Tier 3 on PRs to `main`.
- **`AGENTS.md`:** Documented local test verification commands in Step 2.
