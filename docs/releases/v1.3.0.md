# PantryBot Release Notes — v1.3.0

- **Release Date:** October 19, 2026
- **Milestone:** `v1.3 — User Accounts, Cloud Sync & Legal Foundation`
- **Tickets Closed:** `#523` (Ticket #26), `#524` (Ticket #27), `#525` (Ticket #28), `#526` (Ticket #29), `#527` (Ticket #30), `#528` (Ticket #31)
- **Production Environment:** [pantrybot.dev](https://pantrybot.dev)

## Executive Summary

PantryBot `v1.3.0` introduces **passwordless Single Sign-On (Google & Apple SSO), multi-tenant PostgreSQL Row-Level Security (RLS) cloud persistence, bi-directional cross-device synchronization, self-serve GDPR/CCPA data export and deletion controls, and a complete legal compliance foundation (`/privacy`, `/terms`, and global footer)**.

While anonymous **Zero-Key Guest Mode** remains 100% functional out-of-the-box, shoppers can now sign in with one click to synchronize their **Virtual Freezer inventory**, **My Stores preferences**, **Home ZIP code**, and **Macro/Dietary profiles** across phone, tablet, and desktop.

---

## Key Capabilities & Highlights

### 1. Supabase Auth Foundation, Edge Middleware & Google SSO (Ticket #26 / `#523`)
- **`@supabase/ssr` Client, Server & Edge Middleware (`src/lib/supabase/`, `src/middleware.ts`):** Cookie-based session verification and automatic token refresh across Next.js 15 Server Components, Route Handlers, and Client Components.
- **Google OAuth 2.0 / PKCE Callback (`/auth/callback`):** Exchanges authorization codes for `HttpOnly`, `SameSite=Lax`, `Secure` session cookies with open-redirect sanitization.
- **Zero-Key Offline Resilience:** If `NEXT_PUBLIC_SUPABASE_URL` or `NEXT_PUBLIC_SUPABASE_ANON_KEY` are omitted, PantryBot gracefully falls back to a multi-tenant SQLite local session mode without errors.

### 2. Multi-Tenant PostgreSQL Schema with Row-Level Security (Ticket #27 / `#524`)
- **Strict PII Minimization (`supabase/migrations/20261019000000_v1_3_multi_tenant_rls_schema.sql`):**
  - `public.users`: Stores only an opaque `id` (`UUID`), `email`, optional `display_name`/`avatar_url`, and SSO `provider`. Zero passwords, zero street addresses, and zero phone numbers.
  - `public.user_preferences`: Persists `default_zip`, `favorite_store_ids`, `macro_goal`, `dietary_constraints`, `vessel_archetype`, `target_servings`, `pinned_ingredient_ids`, and `on_hand_ingredient_ids`.
  - `public.user_freezer_items` & `public.user_saved_recipes`: Cloud counterparts for Virtual Freezer roasts and saved batch recipes with `ON DELETE CASCADE`.
- **Database-Engine Isolation (RLS):** Enabled `ROW LEVEL SECURITY` on all user tables with explicit `SELECT`, `INSERT`, `UPDATE`, and `DELETE` policies enforcing `auth.uid() = user_id`.

### 3. Bi-Directional Cloud Sync & Guest-to-Account Migration (Ticket #28 / `#525`)
- **`useUserSync` Hook (`src/hooks/useUserSync.ts`) & `/api/sync` Route:** Reconciles local state with cloud storage upon login and automatically pushes changes when users update their ZIP code, store filters, nutrition profile, or Virtual Freezer stock.
- **1-Click Guest Data Merge Prompt:** Detects existing anonymous `localStorage` Virtual Freezer items upon login and prompts the user to merge them into their authenticated account.
- **Offline Mutation Queue:** Queues preference and freezer updates in `localStorage` when offline and automatically flushes them when browser connectivity returns.

### 4. Account Management UI & Self-Serve Privacy Controls (Ticket #29 / `#526`)
- **Account Management Drawer (`src/components/AccountModal.tsx`):** Accessible from the top navigation bar, displaying linked SSO provider, RLS isolation badge, sync status, and active personalization summary.
- **1-Click Data Portability (`"Export My Grocery Data"`):** Downloads a formatted `pantrybot-user-data-YYYY-MM-DD.json` archive containing the user's profile, preferences, Virtual Freezer inventory, and saved recipes (`GET /api/account`).
- **Right to be Forgotten (`"Delete Account & Data"`):** 2-step confirmation flow (`DELETE /api/account`) that permanently purges the user's account and cascades deletion across all database tables and local storage.

### 5. Sign in with Apple & API Security Hardening (Ticket #30 / `#527`)
- **Sign in with Apple:** Added Apple HIG-compliant SSO button and OAuth provider flow alongside Google Sign-In.
- **Endpoint Rate Limiting & CSRF Defense (`src/lib/security/rate-limit.ts`):** Added sliding-window IP rate limiting (`429 Too Many Requests` with `Retry-After` headers) and `Origin`/`Host` CSRF verification across `/auth/callback`, `/api/sync`, `/api/account`, and `/api/freezer`.

### 6. Legal Foundation & Global App Footer (Ticket #31 / `#528`)
- **Global Footer (`src/components/AppFooter.tsx`):** Mounted in `src/app/layout.tsx` with `© 2026 PantryBot. All rights reserved.`, version status badge, and direct links to Privacy Policy, Terms & Conditions, and Contact Support (`mailto:support@pantrybot.dev`).
- **Privacy Policy (`/privacy`) & Terms of Service (`/terms`):** Dedicated static routes detailing PantryBot's strict PII minimization, zero data brokerage pledge, cookie security, and retailer price/coupon disclaimers.
