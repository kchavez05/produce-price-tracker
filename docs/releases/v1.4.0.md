# PantryBot Release Notes — v1.4.0

- **Release Date:** October 19, 2026
- **Release Title:** `v1.4.0 — Developer Platform, OpenAPI 3.1 & Interactive Swagger UI Console`
- **Target Branches:** `develop` → `main`
- **Production Environment:** [pantrybot.dev](https://pantrybot.dev)

---

## Executive Summary

PantryBot `v1.4.0` marks our transition into an open, extensible developer platform by aligning the entire backend with **OpenAPI 3.1.0 standards** and introducing an interactive **Swagger UI console** at [`/docs`](https://pantrybot.dev/docs).

Whether building companion mobile apps, integrating automated shopping list bridges, running offline tests, or inspecting data pipelines, developers can now explore typed request and response schemas, copy live specification URLs, and execute queries in real time with zero-key offline resilience.

---

## Key Capabilities & Highlights

### 1. OpenAPI 3.1.0 Specification (`src/lib/openapi/spec.ts` & `/api/openapi.json`)
* **Complete REST Architecture Across 8 Core Domains:**
  1. **Dashboard & Deals (`GET /api/dashboard`):** Real-time commodity rankings, 3-dish stew/casserole meal-prep trios, N-store basket optimizer, wholesale club benchmarks, and 6-week cycle signals.
  2. **Locations & Stores (`GET /api/locations`):** Supported supermarket chains (Kroger, Safeway, ALDI, Walmart, Target, Sprouts), localized banner names, and store features.
  3. **Virtual Freezer (`GET, POST, PATCH, DELETE /api/freezer`):** Virtual Freezer inventory CRUD, weighted-average cost basis tracking, and multi-week protein arbitrage.
  4. **Saved Recipes (`GET, POST, DELETE /api/saved-recipes`):** Blueprints and bookmarked custom AI recipes.
  5. **AI Meal Planner (`POST /api/ai-meal-plan`):** Gemini 2.5 Flash batch-prep trio generator with zero-key offline resilience fallback.
  6. **Cloud Sync (`GET, POST /api/sync`):** Cross-device synchronization with PostgreSQL RLS and local SQLite store.
  7. **Account Management & GDPR/CCPA (`GET, POST, DELETE /api/account`):** Local & SSO sessions, 1-click JSON data export archive, and GDPR right-to-be-forgotten deletion.
  8. **Weekly Automation & Cron (`GET, POST /api/cron/weekly-sync`):** Automated circular refresh, Friday Weekend Meal Prep Digest, and Smart Push notifications.
* **Component Schemas:** Complete OpenAPI component schemas covering domain models: `DashboardPayload`, `FreezerItem`, `RecommendedDish`, `StoreOffer`, `ScoredCommodity`, `UserProfile`, `UserPreferences`, `WeeklySyncCronResult`, `UserDataExportArchive`, etc.
* **Security Schemes:** Documented `LocalSessionCookie` (`pantrybot_local_session`) and `VercelCronHeader` (`x-vercel-cron`).
* **CORS & Caching:** Standardized CORS headers (`Access-Control-Allow-Origin: *`) and cache controls on `GET /api/openapi.json` and `OPTIONS /api/openapi.json`.

### 2. Interactive Swagger UI Console (`src/components/SwaggerUIConsole.tsx` & `/docs`)
* **Embedded Client Console:** Zero initial bundle hydration penalty powered by dynamic client-side `swagger-ui-dist` import with loading skeleton and error boundary.
* **PantryBot Theme Styling:** Custom emerald/slate theme overrides matching the PantryBot aesthetic (rounded cards, clean method badges, accessible contrast).
* **Developer Controls:** 1-click OpenAPI Spec URL copy to clipboard, direct raw JSON download link, and quick tag filtering pills (*Dashboard & Deals*, *Virtual Freezer*, *Saved Recipes*, *AI Meal Planner*, *Cloud Sync*, *Account*, *Cron*).
* **Route Aliases & Redirects:** Direct access via `/docs`, `/api-docs` (redirect), and `/swagger` (redirect in `next.config.ts`).
* **Navigation:** Added direct "API Docs" link into the global `AppFooter.tsx`.

### 3. Static Schema Exports & Automation
* **Static Fallback Files:** Emitted static copies at `docs/openapi.json` and `public/openapi.json` for offline CI linters and tools.
* **Sync Script (`npm run openapi:export`):** Automated script in `package.json` to keep static JSON files in sync with TypeScript specifications.

### 4. Automated Test Coverage
* **Unit Tests (`tests/unit/backend/openapi-spec.test.ts`):** 7 tests validating OpenAPI 3.1.0 versioning, 8 route paths, HTTP methods, 200 response contracts, component schemas, security schemes, and disk file sync.
* **Smoke Tests (`tests/smoke/backend/openapi-smoke.test.ts`):** 2 tests verifying `/api/openapi.json` HTTP 200 JSON delivery, CORS origin headers, and CORS OPTIONS preflight.
