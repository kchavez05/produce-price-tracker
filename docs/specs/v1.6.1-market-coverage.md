Use generic defaults with optional precision where appropriate (for example apples, potatoes and salmon), separate cooking-relevant foods/forms/cuts, and reviewed one-way same-form specific-to-general rules. Generic ownership never establishes a named variety. Explicit No on a required generic identity overrides derived coverage. Shared market membership establishes no ownership or substitution.

Retain subtype-specific USDA evidence and documented curated choices where exact evidence is missing. The existing held-source set remains held. Do not reuse the whole/ground spice general-reference exception to invent named-variety identity links.
