## Provenance contract

Each upsert explicitly records `sourcePurpose: "general-reference"`. The compiled link records `purpose: "general-reference"` and the matching ingredient `familyId`. A shared reference establishes the family association only; it is not evidence that USDA distinguishes the cooking form or supplies matching nutrition.

Existing source links default to exclusive `identity` evidence. Their interpretation and all 83 previous approval payload hashes are unchanged. Sharing is permitted only when all references have the same purpose, family and fingerprint. Duplicate ingredient/source pairs, mixed exact/general claims, cross-family sharing, and inconsistent fingerprints fail validation. A withdrawal removes only that ingredient's reference. Changed shared source evidence requires coordinated review of every linked form before publication; partial fingerprint refreshes fail closed rather than silently retaining inconsistent evidence.

The curation reader now accepts both purposes. Older curation tooling rejects the new purpose/field; update the tool before replaying the new artifact. The public inventory API, browser caches, owner-bound queues, and accepted-ID contract are unchanged. Source records, references, and approval metadata remain outside the browser runtime projection.
